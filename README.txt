WP AI Factory
=============
نرم‌افزار تولید وب‌سایت وردپرسی با کمک DeepSeek (به‌صورت دستی/Copy-Paste).

پیش‌نیاز: Python 3.10+ روی Windows 11

اجرا:
1) start.bat را اجرا کنید.
2) مرورگر روی http://127.0.0.1:5000 باز می‌شود.
3) پروژه بسازید، نیازمندی‌ها را وارد کنید، معماری را تأیید کنید، پرامپت بسازید،
   به DeepSeek بدهید، پاسخ JSON را در بخش Import وارد کنید و فایل‌ها را دریافت کنید.
